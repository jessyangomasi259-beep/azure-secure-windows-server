# Serveur Windows Azure sécurisé, sauvegardé et supervisé

## Présentation

Ce projet présente le déploiement d’un serveur Windows dans Microsoft Azure pour répondre aux besoins d’une petite entreprise.

L’environnement sera conçu afin d’assurer :

- la sécurité des accès ;
- la segmentation réseau ;
- la gestion des autorisations avec Azure RBAC ;
- la sauvegarde et la restauration des données ;
- la supervision du serveur ;
- la détection des incidents ;
- la maîtrise des coûts Azure.

## Scénario

Une petite entreprise souhaite héberger une application interne sur un serveur Windows Azure. Le serveur doit être administrable à distance, protégé contre les accès non autorisés, sauvegardé automatiquement et supervisé afin de détecter rapidement les problèmes.

## Services Azure prévus

- Azure Virtual Machines
- Azure Virtual Network
- Network Security Group
- Microsoft Entra ID
- Azure RBAC
- Azure Backup
- Recovery Services Vault
- Azure Monitor
- Log Analytics Workspace
- Azure Monitor Agent
- Cost Management
